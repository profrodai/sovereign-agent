# v0.5 Unit 1 — compatibility foundation

Python floor is 3.13. `zeocore>=0.5,<0.6` is a required dependency. 0.5.0 is
the minimum tested ZeoCore; ZeoCore 0.5.0 `invoke_async` still swallows
cancellation. Sovereign keeps `invoke_cancellable` until an allowed 0.5.x
release stops catching `BaseException`. See [compatibility.md](compatibility.md).

Sovereign runtime evidence types are `RuntimeCapabilityAssertion` and
`RuntimeCapabilityManifest`. The v1 wire key remains `capability_manifest`.
Optional `runtime_requirements` and `allowed_capabilities` are additive.
