usage: sovereign-agent [-h] [--root ROOT] [--version]
                       {doctor,init,actor,outcome,plan,run,status,inspect,inbox,ruling,verify,accept,demo,supervisor,pulse} ...

Learn how outcomes become governed, evidence-backed work.

positional arguments:
  {doctor,init,actor,outcome,plan,run,status,inspect,inbox,ruling,verify,accept,demo,supervisor,pulse}
    doctor              check the offline learning environment
    init                create sovereign.toml and the local ledger
    actor               inspect actors
    outcome             define outcomes
    plan                activate an outcome and add a SOW
    run                 assign and invoke one actor
    status              explain outcome and SOW state
    inspect             show inventory, cash, events and outcomes
    inbox               list an actor's durable mailbox
    ruling              record a decision
    verify              run deterministic verification
    accept              accept an outcome under authority
    demo                run a scripted teaching scenario
    supervisor          reconcile leases, expired claims, and hard-killed
                        assignments (the runtime loop; not 'service' [future
                        OS hosting, unimplemented] or 'pulse' [the separate
                        proactive-wake command below, never called from here])
    pulse               sale -> signal -> deterministic wake gate -> proactive
                        governed work, created without a human prompt
                        (distinct from 'supervisor'; '--once' is the only
                        shape this command has)

options:
  -h, --help            show this help message and exit
  --root ROOT           organization directory
  --version             show program's version number and exit
