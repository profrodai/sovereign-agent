# v0.7 Unit 9 — artifacts and repository delivery

`ArtifactStore` keeps blobs by digest with manifest, size, media type, producer
lease, retention, and redaction state. Transfers resume and reject digest/size
mismatch. `RemoteWorktree` creates one bounded worktree/branch per execution.
Commit existence and remote containment are proven separately. Workers cannot
self-merge. Failures are preserved for bounded diagnosis.
