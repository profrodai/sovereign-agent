# v0.7 Units 3–5 — Docker, rootless Podman, SSH

`DockerWorker` is a real backend: digest-pinned images, non-root, dropped
capabilities, no-new-privileges, read-only root where possible, explicit mounts,
no engine socket in the execution container, bounded create/start/exec/stop/kill/remove,
and cleanup only by execution labels plus the current fencing token.

`PodmanWorker` shares that contract with UID/GID mapping and measured `keep-id`.
macOS Podman-machine absence is reported as unenforced, not as a silent pass.

`SshWorker` pins host identity (no unattended TOFU), uses a dedicated account
and scoped key, verifies content-addressed inputs, and treats disconnect as
`unknown` until Unit 10 reconciles.
