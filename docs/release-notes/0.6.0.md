# v0.6.0 release notes

Capability-native single-node runtime. No fleet, no second capability schema.

- Default `run_task` / native provider path uses `make_session_callable_surface`.
- Frozen catalogs persist per session; resume refuses a changed registry.
- Durable capability approvals and concurrency leases survive process restart.
- ZeoCore 0.5.0 `invoke_async` still swallows `CancelledError`; Sovereign keeps
  `invoke_cancellable` until upstream stops catching `BaseException`.
- `@register_tool` remains public and deprecated, with removal planned for
  2027-02-23 pending a breaking-change ruling.

See [migration-v0.5-to-v0.6.md](../migration-v0.5-to-v0.6.md) and
[compatibility.md](../compatibility.md).
