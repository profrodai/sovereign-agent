# sovereign-agent 0.3.0

These notes aggregate the release fragments in this directory.

## Added

- Native Codex CLI and Claude Code providers with recorded-fixture conformance,
  capability probes, normalized events, and fresh/resume/fork session handling.
- Governed, worktree-isolated repository execution with fenced locks and
  evidence-backed delivery.
- Persistent seat registry, durable local relay, and governed requests producing
  finalized, redacted execution receipts.

## Compatibility

- All 67 v0.2 top-level public symbols remain. `run_task` is the convenience
  wrapper over the native-provider path, existing tool registries remain valid,
  and schema-v1 sessions are read without in-place migration.
- No public symbol is deprecated in 0.3.0.
- Core installation remains usable without optional backends.

## Security and operations

- Admission and missing evidence fail closed; repository mutation is serialized
  in safe worktrees without hard reset.
- Default gates use recorded providers and sanitized receipts. Live probes are
  opt-in, name their credential, and provide a cost estimate.
- Filesystem isolation is not described as network isolation.

## Teaching surface

The five chapters intentionally remain the v0.2 substrate tutorial. Numbered
v0.3 unit documents teach the new release surface; see
[`../teaching-surface.md`](../teaching-surface.md).
