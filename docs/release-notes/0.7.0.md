# v0.7.0 release notes

Bounded production execution fleet on the v0.6 coordinator. Native Docker and
rootless Podman workers, authenticated SSH workers, capability-aware fail-closed
placement, reservations, secret leases, network enforcement with evidence,
content-addressed artifacts, and reconciliation that forbids last-write-wins.

ZeoCore remains the capability contract layer. It is not a scheduler.

A git tag is not a public release until `make verify-pypi`.
