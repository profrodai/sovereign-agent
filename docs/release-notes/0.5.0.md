# v0.5.0 release notes

Capability migration: ZeoCore owns reusable powers, Sovereign Agent owns
supervised execution. Adds `CapabilityExecutor`, `CapabilityContextFactory`,
a frozen per-execution catalog with reversible provider projection,
pre-invoke approval, concurrency locks driven by ZeoCore `ConcurrencyMode`,
and redacted invocation evidence on receipts.

Python floor is now 3.13 and `zeocore>=0.5,<0.6` is a required dependency.
Runtime/provider evidence types are `RuntimeCapabilityAssertion` and
`RuntimeCapabilityManifest`; the v1 wire key remains `capability_manifest`.

The legacy tool surface (`register_tool`, `ToolRegistry`, `ToolResult`,
`make_builtin_registry`) still imports and is deprecated.

See the unit documents under `docs/v0.5-unit*.md` and the
[migration guide](../migration-v0.4-to-v0.5.md).

This git tag is the capability-migration snapshot. It is not moved. The first
truthful public 0.5 line is [0.5.1](0.5.1.md).
