# v0.4.0 release notes

Governed connectivity: authenticated local API, Zero Employee serialized
connector, relay v2, seat supervision, durable approvals, channel delivery
receipts, plugin allowlists, coordinator lease, backup/restore, and
copy-on-write upgrade from v0.3 runtime roots.

See the unit documents under `docs/v0.4-unit*.md` and the
[operator guide](../v0.4-operator-guide.md).
