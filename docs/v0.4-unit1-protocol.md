# v0.4 Unit 1 — protocol and authenticated local API

The local API speaks HTTP/1.1 over a Unix socket. Every request is a
`ProtocolEnvelope` signed with HMAC-SHA256 over canonical JSON with the
signature field emptied. Authentication proves the configured caller; it
does not prove that a Zero Employee ruling is valid.

Done when replay, body mutation, unsupported majors, unknown required
fields, idempotency conflicts, and observer-forbidden mutations have
typed refusals.
