# v0.7 Unit 4 — rootless Podman

`PodmanWorker` (`worker_backend="podman"`) shares the Docker conformance
contract: digest-pinned images, dropped capabilities, no engine socket in
the execution container, and fencing-labelled cleanup. UID/GID mapping and
measured `keep-id` are recorded as evidence. On macOS, absence of a Podman
machine is reported as unenforced, never as a silent pass.
