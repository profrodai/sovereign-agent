# v0.6 operator notes

## Ownership

| Concern | Owner |
|---|---|
| Capability ID, schema, guards, effects, requirements, concurrency declaration, projection, invocation record | ZeoCore |
| Runtime commands, admission, approvals, durable locks, catalog freeze, evidence persistence, receipts | Sovereign Agent |

## Failure modes

- **Catalog mismatch** (`SA_CATALOG_MISMATCH`): the live registry digest
  differs from the frozen session catalog. Resume refused.
- **Requirements / admission**: capability is not granted or worker evidence
  cannot satisfy declared requirements.
- **Projection collision**: two capabilities or a runtime command share a
  provider name.
- **Contention**: durable lock not acquired before `acquire_timeout`.
- **Cancellation**: `CancelledError` is terminal evidence, never
  `ZEO_CAP_UNEXPECTED`.
- **Approval**: pending records store digests only. Approve once; a second
  resume is idempotent.
- **Receipt verification**: `capability_invocation_refs` must exist on disk
  and match `capability_catalog_digest`.
