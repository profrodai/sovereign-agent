# v0.7 Unit 1 — worker protocol and fencing

The coordinator speaks a versioned, length-prefixed JSON protocol (`1.0`):
register, probe, dispatch, heartbeat, event, artifact, completion, cancel, ack.

`WorkerIdentity` binds worker id to process instance, host, backend, package
version, protocol version, and a monotonic `FencingToken`. Canonical event,
artifact, and completion frames require the current lease and token. Expired
workers may use only the quarantine channel. Sequence numbers resume from the
last acknowledgement. Workers cannot admit work, mint executions, or finalize
receipts.
