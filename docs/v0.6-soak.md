# v0.6 72-hour soak

This is an operator gate. CI runs the same harness compressed.

```bash
# Compressed (seconds), same fault classes:
python scripts/soak_single_node.py --compressed

# 72-hour operator run:
python scripts/soak_single_node.py --hours 72 --runtime ./runtime-soak
```

The harness restarts the process, exercises capability invoke, approval
pause/resume, relay claim recovery, and a scheduler tick, then writes
`soak-receipt.json` under the runtime directory.
