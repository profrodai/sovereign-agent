# Tutorials

These tutorials form a learning path for readers who know basic Python. Follow
them in order; each introduces one new idea and points to a tested repository
example.

1. [Build your first agent](first-agent.md) — task, capability, result.
2. [Author typed capabilities](capabilities.md) — inputs, effects, and results.
3. [Inspect sessions and traces](sessions-and-traces.md) — understand a run.
4. [Write deterministic tests](testing.md) — test without tokens.
5. [Add rules and human approval](structured-and-approval.md) — keep policy in
   Python.

Afterward, use the [how-to guides](../how-to/configuration.md) for specific
tasks or study the [build-from-scratch chapters](../chapters/index.md).

## Cost and prerequisites

Tutorials 2–5 use repository examples and can run offline. The first tutorial
uses a real OpenAI-compatible model after an explicitly labeled configuration
step. Python 3.13+ is required throughout.
