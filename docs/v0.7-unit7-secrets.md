# v0.7 Unit 7 — secret broker

`SecretBroker` resolves opaque `env:` / `file:` references only after admission
and placement. Short-lived execution leases inject values only at process spawn.
Secrets are excluded from prompts, catalogs, approvals, command lines, and
durable environments. Leases revoke on completion, cancellation, expiry, or
fencing. External vaults remain plugins.
