# v0.6 Unit 8 — legacy surface

`register_tool`, `ToolRegistry`, and `ToolResult` remain compatibility-only.

Dated removal plan: **2027-02-23**, subject to a separately filed
breaking-change ruling. Removal is not required to ship v0.6.

Unrepresentable semantics are refused rather than adapted:

- runtime command names (`complete_task`, `handoff_to_structured`,
  `abort_execution`, `session_status`)
- `verify_args` hooks
- non-object JSON parameter schemas
